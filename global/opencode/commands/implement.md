Require a bare positive integer issue number; otherwise ask for a valid number and stop.

Implement the approved plan for issue #$1. If no issue number or approved plan is available in the conversation, ask for the missing information and stop. Use gh to read the issue. Follow the repository instructions and existing patterns. Add or update tests and documentation as needed. Run the relevant quality checks, then summarize the changes, results, and any unresolved risks. Do not commit, push, or open a PR at this stage.
