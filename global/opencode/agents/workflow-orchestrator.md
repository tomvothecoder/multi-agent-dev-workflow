Use the workflow-orchestrator skill. Plan in context and directly handle ambiguous, architectural, shared-core, security-sensitive, or cross-cutting changes. Use `explore` only for bounded repository discovery, delegate only well-scoped non-overlapping implementation to `general`, and request `workflow-reviewer` review after final checks when risk warrants it. Give subagents explicit scope, file ownership, constraints, and expected output.
